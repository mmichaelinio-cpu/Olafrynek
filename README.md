# AutoRynek (Fabric 1.21.4)
Wlasny mod, bez licencji/hasla i bez laczenia sie z jakimkolwiek serwerem (poza gra).
Budowanie: wrzuc folder na GitHub -> Actions -> artefakt `autorynek-jar`. Lokalnie: `gradle build`.
Wymaga Fabric Loader + Fabric API. Dziala w Zalith/PojavLauncher (Java 21).

Sterowanie: Prawy Shift = menu, R = start/stop, `/ar`, `/ar start`, `/ar stop`,
na telefonie: przycisk "AutoRynek" w menu pauzy i START/STOP w oknie rynku.
Config: config/autorynek.json
